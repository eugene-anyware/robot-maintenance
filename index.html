🔴 Using local storage only — data not shared
How to set up Supabase (one-time, ~5 minutes)
  1. Go to supabase.com and sign up for free
  2. Click "New project", give it a name (e.g. "robot-maintenance"), set a password
  3. Once the project is created, go to SQL Editor and run this SQL: 
    CREATE TABLE app_data (
  key TEXT PRIMARY KEY,
  value JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE app_data ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all" ON app_data FOR ALL USING (true) WITH CHECK (true);
ALTER PUBLICATION supabase_realtime ADD TABLE app_data;
  4. Go to Storage → New bucket → name it maintenance-photos → check Public bucket → Create
  5. Go to Settings → API and copy your Project URL and anon public key
  6. Paste them below and click Connect

Step 1: Create a Webhook in Teams

  1. Open Microsoft Teams
  2. Go to the channel where you want reminders
  3. Click the ... (three dots) next to the channel name
  4. Select "Workflows"
  5. Search for "Post to a channel when a webhook request is received"
  6. Click it, follow the setup, name it "Maintenance Reminders"
  7. Copy the webhook URL it gives you
  8. Paste it below and click "Save & Test"

⚙️ GitHub Integration — Automatic & Manual Reminders

GitHub Actions sends scheduled reminders automatically every day and week. It also powers the "Send Now" buttons below without any CORS issues.

🔴 GitHub not configured — "Send Now" will try direct (may hit CORS)
One-time setup (~3 minutes)
  1. Push this project to GitHub (if you haven't yet)
  2. In your GitHub repo → Settings → Secrets and variables → Actions → New repository secret
  3. Name it TEAMS_WEBHOOK_URL, paste your Teams webhook URL, click Add secret
  4. Go to github.com → your profile → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  5. Give it access to your robot-maintenance repo with Actions: Read and write permission
  6. Copy the token and paste it below with your repo name
